# Source CSV files

Copy the three source files into this folder using these filenames:

- `top_500.csv` — Top 500 with Narrative Features
- `top_250.csv` — Top 250 with Most Fans
- `2026_mov.csv` — 2026 Movies Released

Each file should contain `Rank`, `Title`, and `LetterboxdURI`. CSV files are excluded from Git by the root `.gitignore`; keep your original source data locally and do not commit private or licensed data unless you have permission to redistribute it.
